# AJ Garments CRM — Cutting Master ke liye 1-page guide

Login karein (username/password admin dega). Aap ko sirf **My Lots** aur **New Cutting** dikhte hain; baqi CRM (sales, stock, reports) aap ke liye band hai.

## Naya lot darj karna (New Cutting)

1. **Article** chunein (product ki list se).
2. **Fabric**: naam (e.g. Denim 12oz), quantity aur unit (m / yards / kg / pcs).
3. **Bundle number** aur **Shrinkage %** (optional) likhein — yeh stitching gate pass par chhapte hain.
4. **Sizes**: har size ke saamne cut pieces likhein. Jo size kati nahi, 0 rehne dein ya row hata dein. **Total pieces** khud jur jata hai.
5. Note (optional) likh kar **Save** karein. Lot number (LOT-1001, LOT-1002, …) khud lagta hai.

## Lot dekhna aur theek karna

- **My Lots** mein sirf aap ke banaye lots dikhte hain, stage ke saath (Cutting → Stitching → Washing → Packing → Ready).
- Jab tak lot **Cutting** stage par hai, **Edit** se fabric/sizes badal sakte hain. Stitching par chale jane ke baad edit nahi hota — ghalti ho to admin ko batayein.
- Lot page par **History** mein har entry ka record hai (kis ne, kab, kitne pieces).
- **Gate passes** card se apne lot ka stitching/washing gate pass print kar sakte hain (admin banata hai).
- Aap stage aage nahi barhate (yeh admin karta hai) aur stock se aap ka koi lena-dena nahi.

## Profile

- **Profile** se apna naam aur password badal sakte hain.

## Yaad rakhein

- Ek lot = ek article. Do articles kate hon to do lots banayein.
- Pieces ginti sahi likhein: aage stitching/washing mein isi se farq (shortfall) nikalta hai.
- Phone par bhi chalta hai: browser mein wahi address kholein, menu button (☰) se list.
